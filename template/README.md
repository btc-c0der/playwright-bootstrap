# {{PROJECT_NAME}}

QA automation suite generated by [`create-qaf`](https://github.com/{{ORG_SCOPE}}/playwright-bootstrap), built on `@qaf/core` and `@qaf/eslint-plugin-qaf`.

## Quick start

```bash
{{PKG_MANAGER}} install
{{PKG_MANAGER}} test
```

The example suite runs against a bundled, dependency-free local demo server (`tests/fixtures/server`) so it works immediately with no external app required — see `docs/architecture.md` for a tour, then replace `tests/*/specs` with your own once you're ready to point this at `{{APP_BASE_URL}}`.

## Scripts

| Script | What it runs |
|---|---|
| `test` | The blocking matrix: chromium, firefox, webkit, mobile-chrome, mobile-safari, api |
| `test:web` / `test:api` / `test:mobile` | One platform slice at a time |
| `test:quarantine` | Only `@quarantined`-tagged tests (non-blocking) |
| `test:visual` / `test:visual:update` | Visual regression project; `:update` regenerates baselines |
| `test:a11y` | Accessibility audit project |
| `test:ui` / `test:headed` | Playwright's UI mode / headed debugging |
| `check-quarantine` | Enforces the quarantine ceiling + tag/manifest sync (also runs in CI) |
| `lint` / `typecheck` / `format` | Enforcement — see `docs/conventions.md` and `docs/anti-patterns.md` |

## Updating the framework

`@qaf/core` and `@qaf/eslint-plugin-qaf` are versioned npm dependencies, not a fork — run `{{PKG_MANAGER}} update @qaf/core @qaf/eslint-plugin-qaf` and read the changelog for what's new.
