# Architecture

This repo was generated by `create-qaf` from [playwright-bootstrap](https://github.com/{{ORG_SCOPE}}/playwright-bootstrap). It's a Playwright + TypeScript test suite built on `@qaf/core` (fixtures, base page objects, the locator resolver, quarantine engine, visual/a11y helpers) and `@qaf/eslint-plugin-qaf` (convention enforcement) — both versioned npm dependencies, not vendored code.

## The pieces, and how they compose

```
your test file (tests/**/*.spec.ts)
  -> imports { test, expect } from "@qaf/core"
  -> test.extend fixtures (composed in @qaf/core, one import per spec):
       logger            — structured, per-test/worker/shard logging (never console.*)
       apiClient          — wraps Playwright's `request` fixture
       dataFactory        — namespaced data creation + automatic teardown
       testNamespace      — unique id per test, safe across thousands of parallel runs
       resolve            — the locator resolver (data-testid -> role -> text fallback chain)
       authenticatedPage  — a `page` that's already signed in (via API, not a UI login flow)
  -> your page objects (tests/*/pages/*.ts) extend BasePage/BaseComponent from @qaf/core,
     using `this.find(descriptor)` — never raw `page.locator()`
  -> your journeys (tests/*/journeys/*.ts) compose page-object steps into reusable flows
```

## Test projects

Defined in `playwright.config.ts`:

| Project                           | Purpose                                                | testDir                                   |
| --------------------------------- | ------------------------------------------------------ | ----------------------------------------- |
| `chromium` / `firefox` / `webkit` | Blocking web UI matrix                                 | `tests/web` (excludes `visual/`, `a11y/`) |
| `chromium-quarantine`             | Non-blocking, `@quarantined`-tagged tests only         | `tests/web`                               |
| `mobile-chrome` / `mobile-safari` | Blocking mobile-viewport matrix                        | `tests/mobile`                            |
| `api`                             | Blocking contract/API tests, no browser                | `tests/api`                               |
| `visual`                          | Visual regression, run explicitly (`pnpm test:visual`) | `tests/web/visual`                        |
| `a11y`                            | Accessibility audit, run explicitly (`pnpm test:a11y`) | `tests/web/a11y`                          |

## The bundled demo

`tests/fixtures/server` is a small dependency-free Node HTTP server serving a demo todo
app (`tests/fixtures/todo-app.html`) plus a mock `/api/test-users`, `/api/test-auth/session`,
and `/api/posts` API. `playwright.config.ts`'s `webServer` block starts it automatically.
It exists purely so the example suite runs standalone with no external app — delete
`tests/fixtures/*` and the example specs once you're testing your own app, and point
`APP_BASE_URL`/`API_BASE_URL` (`.env`) at it instead.
